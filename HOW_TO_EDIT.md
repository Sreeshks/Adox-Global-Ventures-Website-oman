# Editing your website

1. Open https://adox-global-ventures-oman.modernmorel8.chatgpt.site/admin/ and sign in with the website owner’s ChatGPT account (shinoypallath16@gmail.com).
2. Choose a page on the left, or Contact & regional links for phone, email, location and country destinations. On a phone, open the menu first.
3. Edit the text, then choose **Save changes**. Wait for the saved confirmation. **Preview website** opens the saved website, not an unsaved draft.
4. **Version history** lets you restore a previous saved version. Restoring creates a new revision.
5. **Export saved content** downloads a backup. **Download current draft** preserves unsaved work if you need it.

If a newer version was saved elsewhere, the editor keeps your draft and asks you to load the latest content rather than overwrite it. If your session expires, download the draft before signing in again.

Only the owner can edit. The Drive account is not the admin login. No developer access was granted. Logo/images, page structure, new pages and account permissions remain developer-managed. The enquiry forms still prepare emails for visitors to send.

The hosted owner sign-in/save needs an initial check in the owner’s session. Authentication logic, persistence, save/restore/conflict handling and the interface have been tested locally; this export does not claim a completed owner-session test on the hosted site.
